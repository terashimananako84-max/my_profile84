「5秒ごとに画像をスライド」

目的：ifを使った繰り返しを作る

イメージ

HTML


<ul class="image-slides">
      <li><img src="img/01.jpg"></li>
      <li><img src="img/02.jpg"></li>
      <li><img src="img/03.jpg"></li>
</ul>

JavaScript


const slides = document.querySelectorAll(".image-slides li");

let current = 0;
slides[current].classList.add("active");

setInterval(() => {
    slides[current].classList.remove("active");
    current++;
    if (current >= slides.length) {
        current = 0;
    }
    slides[current].classList.add("active");
}, 5000);
メモ:
変数current=0 1枚目の画像
setInterval(() => {}, 5000); 5秒ごとに繰り返す
current++; current +=1
if (current >= slides.length) {current = 0;} 画像数をcurrentが上回ったら1枚目に戻る
解説:
条件は()で囲む
{}は処理の範囲
