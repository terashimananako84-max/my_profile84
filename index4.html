「5秒ごとに画像をスライド」

目的：ifを使った繰り返しを作る

イメージ

メモ:
JS=存在しない要素を操作しようとするとエラー(null)になってそれ以降の処理が止まる
解決法:
要素があるときだけ実行させる if (要素) {処理}

HTML


<ul class="image-slides">
      <li><img src="img/01.jpg"></li>
      <li><img src="img/02.jpg"></li>
      <li><img src="img/03.jpg"></li>
</ul>

CSS


.image-slides {
    position: relative;
    width: 100%;
    height: 200px;
}
.image-slides img {
    display: block;
    width: 200px;
    object-fit: cover;
}
.image-slides li {
    position: absolute;
    inset: 0;
    opacity: 0;
    transition: 1.5s ease;
    list-style: none;
}
.image-slides li.active {
    opacity: 1;
}

JavaScript


const slides = document.querySelectorAll(".image-slides li");

let current = 0;
slides[current].classList.add("active");

setInterval(() => {
    slides[current].classList.remove("active");
    current++;
    if (current >= slides.length) {
        current = 0;
    }
    slides[current].classList.add("active");
}, 5000);
let current = 0;

変数(1枚目の画像)

setInterval(() => {}, 5000);

5秒ごとに繰り返す

current++;

current +=1の意味

if (current >= slides.length) {current = 0;}

画像数をcurrentが上回ったら1枚目(current = 0)に戻る

※ 条件は()で囲む
{}は処理の範囲
