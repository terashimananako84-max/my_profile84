「ローディング画面を表示する」

目的：アニメーションの起点と終了後の処理を理解する

イメージ

HTML


<div class="loading">
 <p class="loading-text loading-blink">Loading...</p>
 <div id="loading-screen"></div>
</div>

CSS


#loading-grey {
    background-color: lightgrey;
    position: fixed;
    inset: 0;
    z-index: 9999;
    display: grid;
    place-items: center;
}
#loading-screen-green {
    background-color: lightgreen;
    position: fixed;
    inset: 0;
    z-index: 9999;
    transform: translateY(100vh);
}
.load-blink {
    animation: blink 1s infinite;
}
position: fixed;

要素を画面に固定
ビューポートを基準に配置され、ローディング画面がページ全体を覆える

inset: 0;
要素の上下左右すべてを0にする
  • top: 0;
  • right: 0;
  • bottom: 0;
  • left: 0;
をまとめたようなもの
(position: fixed; と組み合わせると、画面いっぱいに広がる要素になる)
place-items: center
上下左右の両方向に中央揃えする
  • align-items:center;
  • justify-items: center;
をまとめたようなもの
transform: translateY(100vh);

要素をY軸に移動させる。

  • 100vh ：画面の高さ分だけ下に移動
animation: blink 1s infinite;
  • blink ：(定義されている)アニメーションの名前
  • 1s ：1秒に1回
  • infinite ：無限に繰り返す

JavaScript


const loadingAreaGrey = document.querySelector('#loading-grey');
const loadingAreaGreen = document.querySelector('#loading-screen-green');
const loadingText = document.querySelector('#loading p');

window.addEventListener('load', () => {
 loadingAreaGrey.animate(
    {
      opacity: [1, 0],
      visibility: 'hidden',
    },
    {
      duration: 2000,
      delay: 1200,
      easing: 'ease',
      fill: 'forwards',
    }
  );

  loadingAreaGreen.animate(
    {
      transform: [
        'translateY(100vh)',
        'translateY(0)',
        'translateY(-100vh)'
        ]
    },
    {
      duration: 2000,
      delay: 800,
      easing: 'ease',
      fill: 'forwards',
    }
  );

  loadingText.animate(
    [
      {
        opacity: 1,
        offset: .8
      },
      {
        opacity: 0,
        offset: 1
      },
    ],
    {
      duration: 1200,
      easing: 'ease',
      fill: 'forwards',
    }
  );
});
window.addEventListener('load', () => {})

ページの読み込みが完了したら実行する。

  • load ：HTMLだけではなく、画像やCSSなどのリソースも含めて 読み込みが完了したタイミング
  • ローディング画面を読み込み完了後に非表示にする際などに使用
loadingAreaGrey.animate()

要素のアニメーションを実行する。

第一引数：アニメーションのプロパティ

opacity

[1, 0] →
1：完全に表示
0：完全に透明

visibility

'hidden' → アニメーション後に要素を非表示にする

※ opacity: 0だけでは要素自体は残っているため、 クリックなどの操作ができてしまう。

第二引数：アニメーションの設定

duration

アニメーションの時間（ミリ秒）

delay

アニメーション開始までの遅延時間

easing

アニメーションの速度変化

  • linear：一定の速度
  • ease-in：最初がゆっくり
  • ease-out：最後がゆっくり
  • ease：最初と最後がゆっくり
fill

'forwards' → アニメーション終了後も最終状態を保持

translateY

要素を上下に移動させる。

  • 100vh：画面の下からスタート
  • 0：画面中央
  • -100vh：画面の上へ移動

vh = viewport（画面）の高さ
100vh = 画面1個分の高さ

loadingText.animate()

ローディングテキストを徐々に消すアニメーション。

offset

アニメーションの進行度を0〜1で指定する。

  • 0：アニメーション開始時
  • 1：アニメーション終了時
