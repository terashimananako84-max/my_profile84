isset()

変数が設定されているかを確認する

  • $_POST ：POSTデータを $_POST から取得することができる
  • フォーム送信前は$_POST[""]は存在しないため、isset()で確認する必要がある
if (isset($_POST["name"])) {$name = $_POST["name"];}

POSTデータが送られてきている場合だけ、{}の処理をする
フォームから送られてきたデータを $name という変数に入れる

$name === ""

空欄
スペースだけ入力した場合も空欄として扱いたいのであれば、trim()を使う

|| は「または」
&& は「かつ」
$birthday = DateTime::createFromFormat('Y/m/d', $birthDate);

$birthDateのデータを指定した形式('Y/m/d')で DateTimeオブジェクト(日時を扱うクラス)に変換して代入

('Y/m/d'):4桁の年/2桁の月/2桁の日
$birthday === false

$birthdayへの変換に失敗したかのチェック

※ これがtrue なら「不正な日付」となる
例えば、$birthDate = 'abc';の場合は、=== falseはtrueになる

$birthday->format('Y/m/d') !== $birthDate

DateTimeオブジェクト(=$birthday)を、 -> format(''); でY/m/d形式の文字列に戻して比較する

※PHPのDateTimeは日付を補正してしまうので存在しない日付をチェックする

  • 「 !== 」 ：比較演算子で元の$birthDateと(値も型も)完全に一致”しない”かどうかのチェック
  • 「 != 」 ：比較演算子で元の$birthDateと等しくないかどうかのチェック
filter_var()

PHPで値をvalidate*1したり、sanitize*2したりするための汎用的な関数

  • *1 validate：値が正しいかどうかを検証すること
  • *2 sanitize：値を安全な形式に変換すること

今回はメールアドレスの形式が正しいかどうかを検証するために使用

filter_var(チェックする値, 何をするか)
  • ├─ FILTER_VALIDATE_EMAIL → メールアドレス
  • ├─ FILTER_VALIDATE_INT → 整数
  • ├─ FILTER_VALIDATE_URL → URL
  • ├─ FILTER_VALIDATE_IP → IPアドレス

※ filter_var()は、PHP5.2.0以降で使用可能

$today = new DateTime();

DateTimeクラスのインスタンスを作成。()内に指定していないので現在の日時になる

  • $date = new DateTime('2026-01-01'); →2026年1月1日の日時オブジェクト
  • $date = new DateTime('tomorrow'); →明日の日時オブジェクト

if (mb_strlen($name) > 20) {}

文字列の長さをバイト数ではなく、マルチバイト文字を考慮して文字数で取得する関数
mb_strlen(文字列, 文字コード) 文字コードを省略した場合は、内部文字エンコーディングが使用される

$age = $today->diff($birthday)->y;

DateTimeオブジェクト同士の差を計算し、年数を取得する
diff()メソッドはDateIntervalオブジェクトを返し、->yで年数を取得する

htmlspecialchars($name, ENT_QUOTES, "UTF-8")

HTMLエスケープを行う関数。$nameの内容をHTMLで安全に表示できる形式に変換する
htmlspecialchars(文字列, オプション, 文字コード) ENT_QUOTESは、シングルクォートとダブルクォートをエスケープする

JavaScript


            const form = document.getElementById("userForm");

            const nameInput = document.getElementById("name");
            const birthDateInput = document.getElementById("birthDate");
            const mailAddressInput = document.getElementById("mailAddress");

            const errorMessage = document.getElementById("errorMessage");
            const errorText = document.getElementById("errorText");
            const closeError = document.getElementById("closeError");

            closeError.addEventListener("click", function () {
                errorMessage.style.display = "none";
            });

            form.addEventListener("submit", function (event) {
                const name = nameInput.value.trim();
                const birthDate = birthDateInput.value;
                const mailAddress = mailAddressInput.value.trim();
                // 未入力
                if (name === "" || birthDate === "" || mailAddress === "") {
                    event.preventDefault();
                    errorText.textContent = "名前と生年月日とメールアドレスを入力してください。";
                    errorMessage.style.display = "block";
                    return;
                }
                // 生年月日形式
                if (!/^\d{4}\/\d{2}\/\d{2}$/.test(birthDate)) {
                    event.preventDefault();
                    errorText.textContent =
                        "生年月日は「2026/08/31」の形式で入力してください。";
                    errorMessage.style.display = "block";
                    return;
                }
                // 存在しない日付
                const [year, month, day] = birthDate.split("/").map(Number);
                const date = new Date(year, month - 1, day);
                if (
                    date.getFullYear() !== year ||
                    date.getMonth() !== month - 1 ||
                    date.getDate() !== day
                ) {
                    event.preventDefault();
                    errorText.textContent =
                        "正しい生年月日を入力してください。";
                    errorMessage.style.display = "block";
                    return;
                }
                // 未来の日付
                const today = new Date();
                if (date > today) {
                    event.preventDefault();
                    errorText.textContent =
                        "未来の日付は入力できません。";
                    errorMessage.style.display = "block";
                    return;
                }
                // 名前の文字数制限
                if (name.length > 20) {
                    event.preventDefault();
                    errorText.textContent =
                        "名前は20文字以内で入力してください。";
                    errorMessage.style.display = "block";
                    return;
                }
                // メールアドレス形式
                if (!/^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(mailAddress)) {
                    event.preventDefault();
                    errorText.textContent =
                        "正しいメールアドレスを入力してください。";
                    errorMessage.style.display = "block";
                    return;
                }
            })
